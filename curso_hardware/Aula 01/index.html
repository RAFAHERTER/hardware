Ferramentas necessárias

  • Luvas antiestáticas
  • Manta de bancada
  • Pulseira antiestática
  • Cartão para abrir o notebook (Preferencialmente mais rígido)
  • Organizador de parafusos para notebook
  • Álcool isopropílico
  • Pasta térmica
  • Cabo de fonte universal
  • Fonte de bancada (Usada para identificar defeitos na placa mãe e identificar fuga curta ou circuito aberto)
  • Escovinha antiestática
  • pinças e espátulas
  • Kit de chaves
  • Paletas
  • Ferro de solda (RÉ)
  • Solda
  • Pinça a vácuo
  • Ter pelo menos alguns modelos de memória RAM consigo
  • Coolers
  • Gravador de bios

    • Obs: Muitas das vezes que você for abrir um notebook, você vai precisar de ferramentas específicas para aquele modelo, então é bom ter uma boa variedade de ferramentas.

    Além disso, muitos dos problemas de internet e rede pode acabar sendo problema do hardware, então é bom ter um bom conhecimento de hardware para poder identificar o problema.
